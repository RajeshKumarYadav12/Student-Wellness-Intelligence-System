┌──────────────────────────────────────────────────────────────┐
│ ✅ STEP 1: PUSH TO GITHUB (5 minutes)                        │
└──────────────────────────────────────────────────────────────┘

1. Create repository: https://github.com/new
   Name: aura
   Visibility: Public (or Private)
   DO NOT initialize with README

2. Push code:
   cd D:\MovedFromC\Aura
   git init
   git add .
   git commit -m "Initial commit: AURA v1.0"
   git remote add origin https://github.com/YOUR_USERNAME/aura.git
   git push -u origin main

3. Verify: Visit github.com/YOUR_USERNAME/aura


┌──────────────────────────────────────────────────────────────┐
│ 🔥 STEP 2: DEPLOY BACKEND (RENDER) - 5 minutes              │
└──────────────────────────────────────────────────────────────┘

1. Go to: https://render.com
2. Sign up with GitHub → Authorize
3. New + → Web Service
4. Connect your "aura" repository

5. Configure:
   ┌─────────────────────────────────────────────────────────┐
   │ Name:              aura-backend                         │
   │ Region:            Oregon (US West)                     │
   │ Root Directory:    backend                              │
   │ Build Command:     pip install -r requirements.txt     │
   │ Start Command:     uvicorn main:app --host 0.0.0.0 --port $PORT │
   │ Plan:              Free (or Starter $7/mo)              │
   └─────────────────────────────────────────────────────────┘

6. Add Environment Variables:
   ┌─────────────────────────────────────────────────────────┐
   │ MONGODB_URI         mongodb+srv://...                   │
   │ AURA_SALT          <copy from .env file>                │
   │ COUNSELLOR_KEY     <copy from .env file>                │
   └─────────────────────────────────────────────────────────┘

7. Click "Create Web Service" → Wait 3-5 min

8. SAVE YOUR BACKEND URL:
   Example: https://aura-backend-xyz123.onrender.com
   
9. Test: curl https://your-backend-url.onrender.com/health


┌──────────────────────────────────────────────────────────────┐
│ 🗄️ STEP 3: CONFIGURE MONGODB (2 minutes)                    │
└──────────────────────────────────────────────────────────────┘

1. Go to: https://cloud.mongodb.com
2. Select your cluster
3. Network Access → Add IP Address
4. Select "Allow Access from Anywhere" (0.0.0.0/0)
5. Confirm


┌──────────────────────────────────────────────────────────────┐
│ 🎨 STEP 4: DEPLOY FRONTEND (VERCEL) - 3 minutes             │
└──────────────────────────────────────────────────────────────┘

1. Go to: https://vercel.com
2. Sign up with GitHub → Authorize
3. Add New... → Project
4. Import your "aura" repository

5. Configure:
   ┌─────────────────────────────────────────────────────────┐
   │ Framework:         Create React App                     │
   │ Root Directory:    frontend                             │
   │ Build Command:     npm run build                        │
   │ Output Directory:  build                                │
   └─────────────────────────────────────────────────────────┘

6. Add Environment Variable:
   ┌─────────────────────────────────────────────────────────┐
   │ Name:   REACT_APP_API_URL                               │
   │ Value:  https://your-backend-url.onrender.com           │
   │         (Use YOUR Render URL from Step 2!)              │
   └─────────────────────────────────────────────────────────┘

7. Click "Deploy" → Wait 2-3 min

8. Visit your live dashboard! 🎉
   Example: https://aura-abc123.vercel.app


┌──────────────────────────────────────────────────────────────┐
│ ✅ STEP 5: TEST EVERYTHING (2 minutes)                       │
└──────────────────────────────────────────────────────────────┘

Backend:
  curl https://your-backend.onrender.com/health
  Visit: https://your-backend.onrender.com/docs

Frontend:
  Visit: https://your-frontend.vercel.app
  Open browser console (F12) - check for errors
  Test: Click KPI cards, view student details

╔════════════════════════════════════════════════════════════════╗
║                    🐛 TROUBLESHOOTING                          ║
╚════════════════════════════════════════════════════════════════╝

Backend won't start:
  ✓ Check Render logs for errors
  ✓ Verify environment variables are set
  ✓ Check MongoDB Atlas network access

Frontend can't connect:
  ✓ Verify REACT_APP_API_URL in Vercel settings
  ✓ Redeploy frontend after changing env vars
  ✓ Check CORS settings in backend/main.py

Database connection failed:
  ✓ MongoDB Atlas allows 0.0.0.0/0
  ✓ Check MONGODB_URI includes credentials
  ✓ Verify database user has read/write permissions
